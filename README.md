# RecentDrop

A lightweight macOS menu-bar utility that lists your recent files and generates
cloud share links in one click — for Google Drive, OneDrive, Dropbox, kDrive
and iCloud.

This repository hosts the **auto-update feed** (Sparkle) and **release binaries**.
The source code is private.

## Privacy

See [PRIVACY.md](./PRIVACY.md) — RecentDrop has no server, your credentials stay
encrypted on your Mac, no tracking.

## System requirements

- macOS 13 (Ventura) or later
- Apple Silicon or Intel (universal binary)
